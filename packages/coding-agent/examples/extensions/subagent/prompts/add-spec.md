
Work with the user to clarify:
1. What problem this solves and who benefits
2. Type: bug, feature, or refactor
3. Priority: critical, high, medium, or low
4. Acceptance criteria (specific, testable outcomes)
5. Edge cases and constraints

Then save the spec using the spec tool. Set status to `ready` if complete, `draft` if it needs more work.
